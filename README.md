# poetic-torn-paper-poster

Codex Skill：诗意撕纸影像海报。

## 安装到单个项目

将整个文件夹复制到：

`.agents/skills/poetic-torn-paper-poster/`

## 安装为个人全局 Skill

将整个文件夹复制到：

`$HOME/.agents/skills/poetic-torn-paper-poster/`

在 Codex 中可显式使用：

`$poetic-torn-paper-poster`

也允许在任务匹配时自动调用。

## 使用示例

- 上传一张照片并说：`用 $poetic-torn-paper-poster 做海报。`
- 或直接说：`$poetic-torn-paper-poster 高中，阳台，午后，同学`

图片输入时 Skill 会先内部诊断，再直接输出；关键词输入时直接输出海报。
