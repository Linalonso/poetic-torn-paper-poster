# Codex Skill 更新版补丁（V3.3）

## 相对 V3.2 的核心更新

### 1. 新增「纸面干净优先」
- 新增最高优先级原则：**PAPER CLEANLINESS FIRST**。
- 奶油/米白纸张背景必须保持干净、轻盈、透气。
- 不得通过叠加灰绿水彩晕染、墨点/污渍、手稿底纹、泛黄块、通用植物插画等方式制造“复古感”。

### 2. 强化「延伸有源」为「单一来源，单一表现」
- 延伸不仅要来源正确，还要克制、低对比、单一表达。
- 同一区域避免同时叠加剪影 + 水彩 + 墨点 + 纸纹 + 植物线稿等多层效果。
- 延伸强度进一步收紧到主图视觉强度的约 **5%–15%**。

### 3. 强化「右下角非默认装饰区」
- 右下角不得成为多层纹理与装饰堆叠区。
- 若无必要，右下角可完全留白。
- 如需处理，也应以单一、低对比、有来源的轻延伸为主。

### 4. 强化「点缀色使用方式」
- 点缀色依然来自当前画面。
- 但应表现为小面积、边界明确的胶带/短线/日期等设计记号。
- 不应大面积化成脏污水彩或底色晕染。

### 5. 强化「植物延伸形态约束」
- 植物延伸必须保留当前原图植物的形态特征。
- 避免把“图里有植物”泛化为通用花枝/树枝装饰。

**干净奶油纸面 + 清晰撕纸主图 + 少量有来源的低对比延伸 + 动态小面积点缀 + 克制自然的手写题字**
