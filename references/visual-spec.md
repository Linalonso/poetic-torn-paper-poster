# 诗意撕纸影像海报视觉规范 V2.1

## 1. 风格定义

以真实影像为核心，通过不规则撕纸、暖米白纸媒留白、原图元素延伸、动态色彩提取和诗性中文手写题字，把普通照片或关键词场景重新组织成具有记忆感与编辑艺术感的 9:16 竖版影像海报。

关键词：

`宣纸肌理 × 撕纸拼贴 × 真实影像 × 内容延伸 × 大面积留白 × 诗性手写中文 × 动态点缀色 × 编辑设计`

## 2. 画幅与材质

- 比例：9:16。
- 推荐：2160×3840 px。
- 背景：暖米白、奶油、象牙色粗纤维纸张/宣纸。
- 允许：轻微纤维、颗粒、自然纸色差、极轻微折痕。
- 禁止：脏污、重度泛黄、强烈复古滤镜、厚重污渍。

## 3. 主视觉

- 主体为第一视觉中心。
- 图片不是放在“框”里，而是像纸张被撕开后露出主画面。
- 主图面积通常约 45%–70%，按画面决定，不是硬指标。
- 撕纸轮廓自然、有宽窄变化和局部缺口。
- 主图位置不固定，优先服从主体朝向、动势和光线。

## 4. 主体保留

图片输入时优先保持：

- 人物五官、年龄感、发型、姿势、动作；
- 人物之间的关系；
- 关键物件；
- 有辨识度的场景；
- 关键光影；
- 原图最重要的瞬间感。

不要为了构图把照片变成另一个故事。

## 5. 底层延伸

### 允许

从主画面中真实存在的内容提取：

- 植物 → 叶影、枝条影、藤蔓轮廓；
- 水 → 水纹、倒影、水花、反光；
- 山 → 山体层叠剪影；
- 云/天空 → 淡云层、光斑；
- 建筑 → 窗格、门框、屋檐、立面线条或投影；
- 家具 → 椅子、桌腿、秋千等低对比轮廓；
- 地面/光 → 影子、反光、纹理；
- 食物/器物 → 网格、器皿轮廓、重复形状等。

### 不允许

- 原图没有树，却为了“文艺”添加树枝；
- 原图没有湖，却添加水纹；
- 原图没有建筑，却加窗户影；
- 原图没有花，却加花朵装饰；
- 为了填满留白而添加任何无来源装饰。

### 表现强度

延伸层视觉强度约为主图的 10%–25%。应像残影、水印、投影或印刷痕迹，而不是第二张完整照片。

## 6. 留白

- 采用大面积非对称留白。
- 通常 30%–50% 为相对安静区域。
- 留白可承载文字，但不要全部填满。
- 允许“图重、字轻”或“图上、字下”等关系，但不要固定。

## 7. 文案

- 仅一组中文，不分标题、副标题。
- 默认 1–3 行，最多 3 个视觉行。
- 根据内容自动创作，而不是套固定句型。
- 偏生活诗性、轻叙事、克制。
- 不使用英文。
- 不使用模板编号或品类标签。

### 文案示例方向

不要复制示例原句，只参考节奏：

- 夏日童年：写水花、笑声、午后、院子等真实元素。
- 教室/同学：写走廊、课桌、窗光、操场、铃声等具体元素。
- 海边：写海面、风、弯腰拾取、远山等实际内容。
- 食物：写热气、油光、香味、刚出锅、街边日常等实际内容。

## 8. 中文字体

锁定方向：自然手写、文艺、略带书法气质。

要求：
- 笔画轻盈；
- 有呼吸感；
- 稍有自然不规则；
- 像真实题字；
- 易读；
- 不过度毛笔化。

避免：宋体、黑体、圆体、粗标题字、卡通字、夸张商业艺术字。

字号不固定。根据画面、文案和留白动态决定。宁可稍小而有余韵，也不要像广告标题一样压住画面。

## 9. 点缀色

点缀色不预设。

从每张主画面中提取 1 个颜色，优先：
1. 主体上最有记忆点的颜色；
2. 场景的情绪色；
3. 与奶油纸背景有适度对比、但不刺眼的颜色。

用途：
- 小胶带；
- 小撕纸；
- 下划线/短线；
- 日期；
- 小面积印刷痕迹。

形状、位置和数量均不固定。不要让“胶带”成为每张图的必备固定组件。

## 10. 日期

- 使用生成当天日期；
- 格式 `YYYY / MM / DD`；
- 位置随构图变化；
- 可配一条细横线；
- 横线长度约画面宽度 12%–18%，系列内保持视觉稳定。

## 11. 禁止的模板化元素

- TEMPLATE 01/02/03/04；
- POSTER TEMPLATE / CATEGORY；
- 英文副文案；
- 固定蓝色胶带；
- 固定左上/右下布局；
- 固定主图撕纸形状；
- 固定文字位置；
- 固定字号；
- 大标题 + 副标题 + 正文结构；
- UI 卡片、玻璃拟态、科技线框等现代界面语言。
