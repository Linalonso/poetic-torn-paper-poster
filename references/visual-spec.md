# 诗意撕纸影像海报视觉规范 V3.3

## 1. 系统总目标

在保持真实影像核心内容的前提下，用撕纸、宣纸、留白、题字与有限度的延伸设计，把原始照片或关键词场景重组为一张具有诗意、呼吸感、纸媒感和编辑设计感的成品海报。

## 2. 五条 P0 级规则

1. **STYLE PERSISTS. CONTENT RESETS.** 只继承设计语言，不继承上一张图的具体内容。
2. **EXTENSION MUST HAVE A SOURCE.** 所有延伸到底层背景的内容都必须来自当前图片或当前关键词主场景。
3. **DECORATION SERVES THE IMAGE, NOT THE HABIT.** 装饰必须服务当前画面，而不是复用旧习惯。
4. **SUBJECT FIRST. EVERYTHING ELSE SUPPORTS IT.** 主体优先，视觉层级必须清楚。
5. **PAPER CLEANLINESS FIRST.** 纸面干净优先。纸面首先是留白空间，不是堆料空间。

## 3. 输入方式

### A. 用户提供图片
执行：图片诊断 → 主体识别 → 内容冻结 → 版式设计 → 延伸设计 → 文案 → 自检 → 输出成品。

### B. 用户提供关键词
执行：关键词 → 建立主场景 → 冻结场景元素 → 构图 → 延伸设计 → 文案 → 自检 → 输出成品。

## 4. 内容清零机制

允许继承：9:16竖版、奶油宣纸底、撕纸语言、非对称留白、中文手写题字、动态点缀色、日期系统、克制拼贴感。

必须清零：上一任务的人物、植物、建筑、场景、道具、动物、装饰方式、局部布局习惯。

## 5. 图片诊断规则

当输入的是照片时，内部必须判断：
- 主体是什么；
- 哪些内容必须保留；
- 哪些元素可用于延伸；
- 画面的光线、颜色、空间结构；
- 点缀色候选；
- 文案方向。

## 6. 主体识别与视觉层级控制

### 6.1 人物照必须先识别主体人物
综合判断：视觉中心、占比、前景位置、动作是否最明确、谁承载情绪、与镜头关系是否最强。

### 6.2 有多群人物时，区分主体人物与背景人物
例：前景两个小孩喝奶茶是主体，后方顾客是背景人物。

### 6.3 背景人物默认弱化处理
可采用：虚化、降清晰度、降对比、降饱和、裁切、柔和并入环境。

### 6.4 多人共同构成主体时，整体突出
如双人互动、情侣、同学群体、家庭合照，应整体视为主体。

## 7. 基础视觉语言

- 画幅：9:16。
- 背景：奶油色 / 米白色 / 浅象牙色粗纤维宣纸肌理。
- 气质：自然、克制、温暖、安静、诗意、轻复古、编辑感。
- 主图形态：不规则撕纸 / 手工裁切式边缘。
- 留白：大面积非对称留白。

## 8. 背景延伸系统

目标：让主画面自然融入底层纸张，而不是制造第二张图片。

允许：淡剪影、低对比倒影、模糊投影、纹理、局部轮廓、印刷残影、半透明结构。

每个延伸元素都必须回答：**它来自当前图的哪里？**

### 8.1 单一来源，单一表现
每个区域优先只保留一种表达方式，例如：
- 只做人影；
- 只做栏杆影；
- 只做海面反光；
- 只做藤蔓或秋千淡影。

避免同一区域同时叠加：剪影 + 水彩 + 墨点 + 纸纹 + 植物线稿。

### 8.2 延伸强度
建议约为主图视觉强度的 **5%–15%**。

## 9. 反模板漂移规则

- 不形成固定装饰位；
- 右下角不是默认装饰区；
- 信纸 / 手稿底纹不再默认出现；
- 花枝 / 干花 / 叶影 / 树影必须双重检查：有无来源、为何必须放在这里；
- 宁可留白，不要乱补。

## 10. 纸面干净规则（V3.3 新增重点）

### 允许
- 轻微纤维质感；
- 轻微自然颗粒；
- 柔和米白/奶油底色；
- 很轻的自然旧感；
- 轻微层次阴影。

### 禁止
- 脏污块；
- 浓重旧纸感；
- 水渍感过强；
- 明显灰蒙蒙底色；
- 手账拼贴本式的堆叠质感；
- 大面积综合色斑块；
- 做旧滤镜式的过度处理；
- 灰绿/灰褐水彩晕染；
- 墨点、喷溅点；
- 通用手稿底纹；
- 泛黄纸片堆叠。

目标气质：**像一张干净的奶油色艺术纸，而不是一本做旧手账页。**

## 11. 点缀色系统

- 颜色不固定；
- 必须从当前画面提取；
- 用于胶带、短线、日期、小色块、局部撕纸等极小面积元素；
- 位置不固定、形状不固定、数量不固定；
- 不应大面积化成脏污水彩。

## 12. 植物延伸规则

植物延伸必须保留当前原图植物的具体形态特征，避免泛化成通用花枝/树枝插画。

## 13. 中文文案系统

- 整张海报只保留一组中文文案；
- 不分主标题、副标题；
- 默认 1–3 句 / 最多 3 个视觉行；
- 文案必须根据当前图片或关键词独立生成；
- 不出现英文、模板编号、CATEGORY 等模板信息。

## 14. 字体规范

锁定：自然手写感 + 文艺感 + 轻书法气质。

要求：轻盈、有呼吸感、略带自然不规则、清晰易读、像真实题字。

避免：宋体、黑体、圆体、机械电脑字、夸张商业书法字。

## 15. 日期系统

- 使用生成当天日期：`YYYY / MM / DD`；
- 位置根据构图自由调整；
- 旁边可有极细横线，长度约画面宽度 12%–18%。

## 16. 最终执行口诀

- 风格继承，内容清零。
- 主体优先，背景退后。
- 延伸有源，装饰有因。
- 纸面干净，堆料禁止。
- 一个区域，一种语言。
- 宁可留白，不要做旧。
- 先看主角，再感受气息。
