# V3.3 检查清单

## 生成前检查

### 内容层
- [ ] 这是一个新任务。
- [ ] 上一任务内容已清零。
- [ ] 当前输入是唯一语义来源。
- [ ] 已识别当前主体。
- [ ] 若为人物照，已识别主体人物。
- [ ] 已判断背景人物是否需要弱化。

### 构图层
- [ ] 主图位置根据本图重新决定。
- [ ] 留白根据本图重新决定。
- [ ] 文字位置根据本图重新决定。
- [ ] 右下角未被默认占用。

### 延伸层
- [ ] 每个延伸元素都有来源。
- [ ] 没有无来源植物、动物、道具、海鸥、花枝、信纸。
- [ ] 背景人物不会比主体更显眼。
- [ ] 每个区域是否只承载一种延伸语言？
- [ ] 延伸强度是否控制在约 5%–15%？

### 风格层
- [ ] 点缀色来自当前画面。
- [ ] 没有英文。
- [ ] 没有模板编号。
- [ ] 没有固定套路装饰复用。
- [ ] 纸面是否足够干净？
- [ ] 是否存在水彩脏污、墨点、手稿底纹或做旧堆料？如有删除。

## 生成后反向自检
- [ ] 主体是否足够突出？
- [ ] 如果有人物，主角是否清楚？
- [ ] 背景人物是否被合理弱化？
- [ ] 是否错误延续了上一张图的内容？
- [ ] 是否又习惯性在右下角放花枝、旧纸、信纸或堆料？
- [ ] 是否加入了当前图中不存在的元素？
- [ ] 点缀色是否来自当前图？
- [ ] 文案是否简洁、合适？
- [ ] 字体是否符合手写题字感？
- [ ] 是否还能删掉一个不必要的装饰？
- [ ] 纸面是否仍然干净、轻盈、透气？
- [ ] 有无同一区域叠太多层，导致脏乱？
