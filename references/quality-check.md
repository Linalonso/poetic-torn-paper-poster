# 成品质量检查

每次完成前逐项检查。

## 主体
- [ ] 第一视觉主体清楚。
- [ ] 用户上传图片中的主体身份/外观/动作没有被不必要改变。
- [ ] 关键物件和场景关系仍然成立。

## 纸张与撕纸
- [ ] 背景是温暖米白/奶油色纸张，而不是纯白 UI 背景。
- [ ] 撕纸边缘自然、不规则。
- [ ] 没有明显固定模板框。

## 延伸创作
- [ ] 每一个底层延伸元素都能在主画面中找到来源。
- [ ] 没有无来源的树枝、植物、山、水、建筑或装饰。
- [ ] 延伸层足够淡，不与主图争抢。

## 点缀色
- [ ] 点缀色来自当前主画面。
- [ ] 没有默认套用蓝色。
- [ ] 点缀面积小，位置与形式没有固定化。

## 文案
- [ ] 中文文案与当前画面相关。
- [ ] 最多 3 个视觉行。
- [ ] 没有标题/副标题结构。
- [ ] 没有英文。
- [ ] 没有 TEMPLATE / CATEGORY 等模板字样。
- [ ] 字体有自然手写题字感。
- [ ] 字号根据画面动态变化且不过大。

## 日期
- [ ] 日期是生成当天。
- [ ] 格式为 YYYY / MM / DD。
- [ ] 横线长度约画面宽度 12%–18%，比例协调。

## 风格
- [ ] 有大面积非对称留白。
- [ ] 整体像独立设计作品，而不是上一张换图。
- [ ] 没有电商、PPT、现代 UI 或过度装饰感。
